# 📰 每日新闻简报

一个零基础也能用的网页小应用：点一下按钮，自动抓取当天的中文新闻，
按 **政治 / 科技 / 财经 / 生活** 四个板块整理成一份每日简报（每个板块最多 4 条）。

- 纯 HTML / CSS / JavaScript，**不需要安装任何环境、不需要后端**
- 两种浏览方式：**列表浏览**（三板块一览）+ **沉浸浏览**（抖音式竖屏全屏卡片，开发中）
- 每条新闻含：标题、一句话摘要、封面图、来源与时间、原文链接

## 🚀 快速开始

### 方式一：双击打开（最简单）

直接双击 `index.html`，用浏览器打开即可，点「生成今日简报」就能用。

> ⚠️ 这种方式没有本地服务器，只能走 rss2json 降级通道：
> **每个源只返回最新 10 条**（本地代理能拿到约 30 条），
> 科技池候选从约 110 条降到约 40 条，各板块条数会明显变少——属正常现象，不是故障。
> **请用 `start-server.bat` 打开以启用本地代理**（见下面方式二），条数才完整。

### 方式二：本地服务器打开（更稳定，推荐）

**双击项目文件夹里的 `start-server.bat`**，它会自动启动本地服务器并打开浏览器
（地址 `http://localhost:8019/`）。关闭弹出的黑色命令行窗口即可停止。

> 如果双击打开时抓取失败（少数浏览器或网络限制），改用它即可，功能完全相同。

### 方式三：用手机看（同一 WiFi 下）

手机打不开**通常不是浏览器的问题**，而是这两件事没做（2026-10-24 真机验收实测）：

1. 服务默认只注册 `http://localhost:8019/`，手机用 IP 访问会被直接拒绝（返回 HTTP 400）；
   要监听所有网卡得注册 `http://+:8019/`，这需要**管理员权限**。
2. Windows 防火墙默认拦入站，且 WLAN 常被识别为「公用网络」（拦得更严），
   需要放行 TCP 8019。

**一键解决**：双击 `tools/启动服务-局域网.ps1` → UAC 点「是」。
它会自动做完 URL 保留、防火墙放行，并以局域网模式启动服务，最后打印手机地址
（形如 `http://192.168.1.169:8019/`）。

> 手机地址栏要输入**完整**地址（含 `http://` 和端口）——只输 IP 会被浏览器当成搜索词。
> 若装了第三方安全软件（本机实测有腾讯电脑管家），它可能单独拦截，需要在其中放行 8019。

### 通用步骤

1. 用上面任一方式打开页面
2. 点击紫色按钮 **「生成今日简报」**
3. 等待 1~3 秒，简报生成完毕
4. 点击新闻标题或「打开原文 ↗」，在新标签页查看原文

## 📡 新闻来源（RSS）：只用权威官方媒体

所有来源统一取自**中国新闻社**旗下中新网（国家通讯社，官方媒体），按频道分给四个板块：

| 媒体机构 | 频道 | 分类 | 地址 |
|---|---|---|---|
| 中国新闻社 | 中新网要闻 | 政治 | https://www.chinanews.com.cn/rss/importnews.xml |
| 中国新闻社 | 中新网国内 | 政治 | https://www.chinanews.com.cn/rss/china.xml |
| 中国新闻社 | 中新网滚动 | 科技池（不单独成板块） | https://www.chinanews.com.cn/rss/scroll-news.xml |
| 中国新闻社 | 中新网财经 | 财经 | https://www.chinanews.com.cn/rss/finance.xml |
| 中国新闻社 | 中新网健康 | 生活 | https://www.chinanews.com.cn/rss/health.xml |
| 中国新闻社 | 中新网生活 | 生活 | https://www.chinanews.com.cn/rss/life.xml |
| 中国新闻社 | 中新网文化 | 生活 | https://www.chinanews.com.cn/rss/culture.xml |

> 2026-10-20 实测：`culture` 30 条日更、`society` 30 条日更、`edu` 25 条日更、
> `ent` 空源、`hr` 404；`life` 是低频源（当天 10 条、最新 18:40）不是死源，
> 停更告警阈值因此设为 4 天（`SOURCE_STALE_DAYS`）。

**准入机制**：`js/config.js` 里的 `AUTHORITATIVE_MEDIA` 是权威媒体白名单，
抓取前由 `getEnabledSources()` 逐个核对——不在名单里、或 `official` 不为 true 的源一律跳过并在控制台告警。
中新网没有独立科技频道，因此科技板块用「**多频道科技池**」：
把 `TECH_POOL_SOURCES`（要闻 / 国内 / 财经 / 滚动）的条目合并后，
再用 `TECH_KEYWORDS`（29 词）筛科技。**只匹配标题，不匹配摘要**
（匹配摘要时 9 条里约 4 条是误命中）。过宽的"数字/数据/网络"已删除，
"AI""5G" 按独立词匹配（AIGC、CAI 不算命中）。

> 池子合并后必须做三件事，否则会出问题：
> ① 去重：先按 link 去重，再按标题相似度去重（共同前缀 ≥14 字或 Jaccard ≥0.85），
>    实测存在 link 不同、标题只差一两个字的同稿；被判重复的"标题对"会打印在 Console 供核对。
> ② 板块互斥，优先级 科技 > 财经 > 政治 > 生活（同一条新闻只归一个板块）
> ③ 排除词：命中科技词但标题含 政治化 / 外交部发言人 / 双开 / 落马 / 被查 / 问责 /
>    宣讲 / 会见 / 会谈 / 致电 / 贺信 的，打回原板块（如"将科技经贸问题政治化"是时政不是科技）。
>    注意：不要加"商务部/通报/答记者问"——会误杀「商务部：…智能眼镜销售额增长1.1倍」这类真科技稿。
> 详见 `js/app.js` 的 `dedupeAndAssignCategories()`，Console 会打印每步条数。

> 配额在 `js/config.js` 的 `CATEGORY_QUOTA = { 政治:4, 科技:6, 财经:4, 生活:4 }`，
> 列表页与沉浸浏览共用这一张表（`categoryQuota()`），不要再散落硬编码。
> 板块内还有一道"每个源最多 `MAX_PER_SOURCE_IN_CATEGORY`（2）条"的限流
> （多源板块才生效，单一来源板块不限），用轮询方式分配，避免更新最密的源霸占板块。

### 封面图（/api/image）

中新网 RSS 没有图片字段、文章页也没有 og:image，正文配图只能服务端抓文章页取：

- 接口：`/api/image?url=<文章页>`（`start-server.ps1` 接口 3）
- **只认 `/simg/cmshd/` 路径的正文配图**（实测 10 篇里约 3 篇有）；
  侧栏图（`_zsite` / `_zsite_sl` / `_700x1000`）跨文章重复，一律排除，
  取不到就返回 `image: null`，**不退而求其次**
- 入参必须是文章页（路径含 `YYYY/MM-DD/数字.shtml`），频道首页直接 `400 NOT_ARTICLE`
- 文章页域名白名单、24h 内存缓存、3 秒超时、只返回图片 URL
- 前端只对沉浸式"当前 ±1"调用（`js/app.js` 的 `requestArticleCover` / `preloadNeighborImages`），
  失败静默降级：无图时铺分类渐变底（政治红 / 科技蓝 / 财经金 / 生活粉），

### 摘抄正文（/api/article）

「摘抄正文」的要点来自文章页正文，不是 RSS 导语：

- 接口：`/api/article?url=<文章页>`（`start-server.ps1` 接口 3.5）
- **为什么必须有它**：中新网 RSS 的 `description` 常常只有一句导语
  （实测 12~45 字），"致信 / 讲话 / 报告"这类新闻的要点（"指出……""强调……"）
  全在文章页正文里，只摘导语就会漏掉最关键的内容
  （2026-10-23 实测：某条致信新闻导语 45 字只能摘 1 条，正文 251 字能摘 5 条）
- 正文区定位：`class="content_maincontent_content"` → `【编辑` 之间，
  去标签 / 还原 HTML 实体 / 去掉开头电头（中新网、新华社等），上限 6000 字
- 复用取图那套安全规则：域名白名单、文章页校验、3 秒超时 + 重试 1 次、24h 缓存
- 前端：进卡片时预取（`fetchArticleBody`），点「📄 摘抄正文」时按全文摘 5 条；
  取不到正文才退回 RSS 摘要摘 4 条，并在标题里如实标注来源，不把摘要冒充成全文

### 自动配图流水线（三级，**保证每条新闻都有图**）

「配图不可空缺」是硬要求。每条新闻按下面三级依次尝试（`js/aiImage.js`），
**越靠前越"真"**：

1. **新闻原图**（`/api/image`）：抓**这篇文章自己的照片**，按顺序试三级来源——
   ① 文章页正文里的 `/simg/cmshd/` 图（中新网给文章配图专用的目录）；
   ② **站内列表页缩略图**：中新网首页 / 国内 / 生活 / 体育等列表页的每条新闻
      链接里自带缩略图，按文章 ID 精确对应，启动时预热、30 分钟刷新一次
      （很多短讯的文章页正文是 `<!-- 显示图片 -->` **空占位**，只有列表页有图）；
   ③ 正文容器内的 `<img>`（div 配平取真实闭合，绝不往后切 N 字符——
      那一刀会切进页面公共区，见 `错题本.md` ⑤）。
   文章没图就如实返回"无"，交给下一级，**绝不用页面公共区的图顶替**。
   服务端把图**下载到本地** `assets/images/origin/` 再返回地址——
   不用源站外链，否则过几天防盗链或链接失效，页面上就会出现
   "昨天有图、今天空白"。
   下载后还会按**内容哈希去重**：同一张图今天已经给过别的文章，就当"无原图"（`错题本.md` ⑤）
2. **网络意象图**（`/api/stock-image`）：文章本来没图时，按这条新闻的关键词去
   **Wikimedia Commons**（免密钥、CC / 公有领域）找一张贴题的照片。
   查询词是**实体词优先**：先从标题里认出地名 / 机构 / 实物（如"温州""辽宁舰""火箭"），
   用它去搜；认不出才退回板块英文词。
   ⚠️ 两个实测坑已处理：中文**整句标题**在 Commons 里搜不到任何东西
   （只能搜短的实体词）；查询串必须**显式按 UTF-8 解码**（否则中文变乱码、永远落空）；
   搜索时限定 `filemime:image/jpeg`，否则会搜出 PDF / 音频 / 图标。
   同一张图和同一作者**本批只用一次**，避免几条新闻配到同系列图。
   **CC 许可要求署名**——沉浸卡片右下角会显示"意象图 · 来源 · 作者 · 许可"，
   明确告诉读者这不是新闻照片
3. **工具生成**（`/api/code-image` → `tools/news_image_factory.py`）：
   用代码直接画一张 SVG——**不用 AI、不需要密钥、毫秒级返回、几乎不会失败**。
   画面由这条新闻的真实内容决定：讲芯片画电路、讲卫星画轨道、讲股市画柱状，
   同一条新闻每次生成结果完全一致（指纹哈希）

三级都拿不到时的兜底：复用**新闻图库**（`assets/images/news-library/`），
且同一张图本次只给一条新闻用，不会再出现"多条新闻共用同一张图"。

> 为什么没有"开源文生图模型"这一档：本地跑 ComfyUI / FLUX 需要 ≥12GB 显存，
> 本机实测只有 2GB（MX250），该方案已于 2026-10-24 决定放弃，相关文件已从仓库删除。

所有配图统一遵守标准：画面无文字/水印/Logo/边框，1200×1200 方形、主体居中留白，
方图与竖幅裁切都不会切掉主体（工具生成后会按 `STANDARDS` 自检，不达标直接报错）。
  图片 onload 后 0.3s 淡入，不出现白块或占位图标

> 想加/换新闻源：打开 `js/config.js`，先确认媒体机构在 `AUTHORITATIVE_MEDIA` 白名单里，
> 再往 `RSS_SOURCES` 里加一项（非权威来源会被自动拦截）。

## 🛠 技术说明

- **技术栈**：原生 HTML / CSS / JavaScript，无框架、无构建步骤
- **数据抓取**：**本地代理优先 + rss2json 降级**——
  优先走 `start-server.ps1` 的 `/api/feed`（服务端直抓源站，能拿到全部 27~30 条，
  且不受 rss2json 限制）；服务器没启动时自动降级到公共接口
  [rss2json](https://rss2json.com)（只返回最新 10 条）；再失败给中文提示
- **AI 摘要**：已预留接口 `js/config.js` 中的 `generateSummary()`，
  目前直接返回 RSS 自带摘要，以后接入 AI 只需改这一个函数
- **数据存储**：用服务器启动时写入 `.data/stats.json`（换浏览器也不丢）；
  双击打开时自动退回浏览器 localStorage

## ⚠️ 注意事项

- 需要联网才能抓新闻；部分源偶尔不稳定，页面会提示哪个源失败，不影响其他源
